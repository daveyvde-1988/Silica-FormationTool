Silica Formation Editor

FORMATIONS

/1 default is reserved in every team/function menu. Custom formations start at /2.

SETTINGS

Numbers belong to this team and function. Choosing an occupied number swaps the two entries. Requires the later mod update.

Drag the arrow tip to set direction. The pink cross marks the original move order / centre.

PLACE

Click a colored placement button, then click the grid to place its dots. Shift-click dots to add or remove them from the selection. Drag selected dots together; Delete removes the selection. Right-click deletes one dot. Escape returns to Select.

Ctrl+C / Ctrl+V copies selected nodes, including unit choices. Paste selects a new copy with a small offset.

AUTO-SHAPES

Fill: compact automatic sizing. Tactical: spread dots through a manually sized shape, leaving the centre empty. Choose one mode, or neither for an outline.

Enabling assigns distance preferences to all dots, following the current dot layout. Disabling keeps them for manual editing. Legacy roles and unit choices are preserved.

Low: mostly orange/red. High: mostly green/yellow. Enable Auto-preference to apply; moving this slider changes preferences, not node positions.

Replaces ALL dots in this formation, including unit choices. After Generate, size, count and fill changes update that shape without adding dots. Manual edits end live generation. Undo restores the layout before generation.

Fill automatically resizes for compact spacing and can use the centre position. Grid boundaries can limit the count.

Numeric preferences require Si_Formation 2.3.1+. Older mods ignore them.

FILES

One file can contain one or many formations. Loading replaces the current set. Export creates one ZIP containing silica-formations.json for all teams and, when Include PNG images is checked, one cropped PNG per formation. Extract the JSON to load it again.

GRID ZOOM

25–300%. Ctrl + mouse wheel zooms at the pointer. Scroll to reach other parts of the grid.

Select a circle to edit its coordinates and preferred units.

COORDINATES

The move centre is always X 0, Z 0. With direction sensitivity, +X is right of the arrow and +Z is forward along it. Without it, screen-right is world +X and screen-up is world +Z; the arrow is ignored. All coordinates use metres. A full grid interval is the selected scale; half-grid snapping is half that distance.
